# Asset Token Contract

The Asset Token contract is a SEP-41 compliant token that represents tokenized real-world assets. It enforces compliance checks on every transfer and supports advanced features like batch operations, admin handover, minimum holding periods, and dividend management.

- **Contract Address (Testnet):** `CBMCWLSQSWUTLUJFCNBHNBSXMUM3XU7NAQ5TSNERW4HA4ZZBYHLG4ECZ`
- **Standard:** SEP-41 (Token Interface)

## SEP-41 Token Interface

The contract implements the full SEP-41 token interface, so it is interoperable with wallets, DEXs, and other SEP-41 consumers.

### `allowance`

```rust
fn allowance(env: Env, from: Address, spender: Address) -> i128
```

Returns the amount `spender` is allowed to transfer on behalf of `from`.

- **Auth:** None

### `approve`

```rust
fn approve(env: Env, from: Address, spender: Address, amount: i128, expiration_ledger: u32)
```

Sets the allowance for `spender` to `amount`, valid until `expiration_ledger`.

- **Auth:** `from`
- **Errors:** `InsufficientAllowance (2)`

### `balance`

```rust
fn balance(env: Env, id: Address) -> i128
```

Returns the token balance of `id`.

- **Auth:** None

### `transfer`

```rust
fn transfer(env: Env, from: Address, to: Address, amount: i128)
```

Transfers `amount` from `from` to `to`. The transfer is rejected if either party fails the compliance check.

- **Auth:** `from`
- **Errors:** `InsufficientBalance (1)`, `ComplianceCheckFailed (4)`

### `transfer_from`

```rust
fn transfer_from(env: Env, spender: Address, from: Address, to: Address, amount: i128)
```

Transfers `amount` from `from` to `to` using the caller's allowance.

- **Auth:** `spender`
- **Errors:** `InsufficientBalance (1)`, `InsufficientAllowance (2)`, `ComplianceCheckFailed (4)`

### `burn`

```rust
fn burn(env: Env, from: Address, amount: i128)
```

Burns `amount` from `from`.

- **Auth:** `from`
- **Errors:** `InsufficientBalance (1)`

### `burn_from`

```rust
fn burn_from(env: Env, spender: Address, from: Address, amount: i128)
```

Burns `amount` from `from` using the caller's allowance.

- **Auth:** `spender`
- **Errors:** `InsufficientBalance (1)`, `InsufficientAllowance (2)`

### `decimals`

```rust
fn decimals(env: Env) -> u32
```

Returns the number of decimals used by the token.

- **Auth:** None

### `name`

```rust
fn name(env: Env) -> String
```

Returns the token name.

- **Auth:** None

### `symbol`

```rust
fn symbol(env: Env) -> String
```

Returns the token symbol.

- **Auth:** None

## Batch Operations

Batch entry points let callers move or burn tokens for many recipients in a single transaction.

### `batch_transfer`

```rust
fn batch_transfer(env: Env, from: Address, transfers: Vec<(Address, i128)>)
```

Transfers tokens from `from` to each `(to, amount)` pair. Each transfer is individually compliance-checked; the whole call reverts if any transfer fails.

- **Auth:** `from`
- **Errors:** `InsufficientBalance (1)`, `ComplianceCheckFailed (4)`

### `batch_transfer_from`

```rust
fn batch_transfer_from(env: Env, spender: Address, from: Address, transfers: Vec<(Address, i128)>)
```

Batch variant of `transfer_from`, consuming the caller's allowance.

- **Auth:** `spender`
- **Errors:** `InsufficientBalance (1)`, `InsufficientAllowance (2)`, `ComplianceCheckFailed (4)`

### `batch_burn`

```rust
fn batch_burn(env: Env, from: Address, amounts: Vec<i128>)
```

Burns multiple amounts from `from` in a single call.

- **Auth:** `from`
- **Errors:** `InsufficientBalance (1)`

## Admin

### `admin`

```rust
fn admin(env: Env) -> Address
```

Returns the current admin address.

- **Auth:** None

### `set_admin`

```rust
fn set_admin(env: Env, new_admin: Address)
```

Hands over admin rights to `new_admin`. The caller must be the current admin.

- **Auth:** `admin`
- **Errors:** `Unauthorized (3)`

### `mint`

```rust
fn mint(env: Env, to: Address, amount: i128)
```

Mints `amount` to `to`. Only the admin may mint.

- **Auth:** `admin`
- **Errors:** `Unauthorized (3)`, `ComplianceCheckFailed (4)`

## Minimum Holding Period

### `set_min_holding_period`

```rust
fn set_min_holding_period(env: Env, period: u64)
```

Sets the minimum holding period (in ledgers) that a holder must retain tokens before transferring. Only the admin may update it.

- **Auth:** `admin`
- **Errors:** `Unauthorized (3)`

### `get_min_holding_period`

```rust
fn get_min_holding_period(env: Env) -> u64
```

Returns the current minimum holding period in ledgers.

- **Auth:** None

## Dividends

### `set_dividend_deadline`

```rust
fn set_dividend_deadline(env: Env, deadline: u64)
```

Sets the ledger at which dividend claims expire. Only the admin may update it.

- **Auth:** `admin`
- **Errors:** `Unauthorized (3)`

### `reclaim_dividends`

```rust
fn reclaim_dividends(env: Env, holder: Address)
```

Reclaims unclaimed dividends for `holder` after the deadline has passed. Only the admin may call this.

- **Auth:** `admin`
- **Errors:** `Unauthorized (3)`, `DividendDeadlineNotReached (5)`

### `cancel_dividend`

```rust
fn cancel_dividend(env: Env, dividend_id: u64)
```

Cancels a pending dividend distribution. Only the admin may cancel.

- **Auth:** `admin`
- **Errors:** `Unauthorized (3)`, `DividendNotFound (6)`

## Pagination

### `get_holders`

```rust
fn get_holders(env: Env, start: u32, limit: u32) -> Vec<Address>
```

Returns a page of token holders starting at `start`, up to `limit` entries. Use this to enumerate holders without loading the full set.

- **Auth:** None

## Error Codes

| Code | Name | Description |
|------|------|-------------|
| 1 | `InsufficientBalance` | Balance too low for the operation |
| 2 | `InsufficientAllowance` | Allowance too low for the operation |
| 3 | `Unauthorized` | Caller is not authorized |
| 4 | `ComplianceCheckFailed` | Compliance check rejected the transfer |
| 5 | `DividendDeadlineNotReached` | Dividend deadline has not passed yet |
| 6 | `DividendNotFound` | Referenced dividend does not exist |

## Example

Transfer tokens between two compliant addresses:

```rust
// Approve a spender for 100 units
token.approve(&from, &spender, &100, &(env.ledger().sequence() + 1000));

// Transfer 50 units from `from` to `to`
token.transfer(&from, &to, &50);

// Batch transfer to multiple recipients
token.batch_transfer(&from, &vec![&env, (to_a, 10), (to_b, 20)]);
```
